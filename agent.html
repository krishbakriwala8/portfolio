🔄
ReAct Pattern
Agent iterates: Reason → Act → Observe → Synthesize. Up to 6 reasoning steps per task with full transparency.
🛠️
MCP-Style Tool Integration
Tools defined as typed JSON schemas — web search, calculator, text summarizer, and text analyzer. Agent selects tools autonomously.
🧠
Session Memory
Conversation history stored server-side per session. Ask follow-up questions — the agent remembers context from previous turns.
