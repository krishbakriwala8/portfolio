Who I Am

Krish Bakriwala
AI Engineer · Data Scientist
MSc AI Brandenburg UTech Germany

I am a Master's student in Artificial Intelligence with strong foundations in software engineering and scalable system design. I build production-ready applications that combine machine learning, computer vision, agentic AI systems, and modern web technologies.

My experience spans multi-agent AI systems, RAG-based document Q&A, real-time NLP microservices, and computer vision pipelines. Recent projects include a Multi-Agent Travel Intelligence System built with Google ADK, coordinating specialist agents (Weather, Budget, Transport) via an orchestrator using LLaMA 3.3 70B and real free APIs.

I also built an Industrial Defect Detection system using CLIP and Vision-Language Models with zero-shot classification and Grad-CAM explainability, and a Battery Test Failure Assistant with LangChain, RAG pipelines, and Groq LLM. I focus not only on model development but also on clean architecture, agent orchestration, API design, and deployment.

Technically, I work across Agentic AI (Google ADK, LangChain, LangGraph), Multi-Agent Systems, RAG pipelines, Computer Vision (CLIP, OpenCV, Grad-CAM), Generative AI, backend with FastAPI, REST APIs, Docker, data engineering (BeautifulSoup, Scrapy, PostgreSQL, ETL), and workflow automation (Power Automate, N8N, SharePoint).

🌍 Open to roles in Machine Learning, Agentic AI, Backend Engineering, and Software Development across Europe — particularly in Germany.
