## 🤖 Live AI Research Agent

A production-grade multi-tool AI agent available at [`/agent.html`](https://krishbakriwala8.github.io/portfolio/agent.html).

**Architecture:** ReAct (Reason → Act → Observe → Synthesize) with up to 6 reasoning iterations

**Tools (MCP-style schemas):**
- `web_search` — DuckDuckGo real-time search
- `calculate` — safe mathematical expression evaluator
- `summarize_text` — LLM-powered text condensation
- `analyze_text` — sentiment, themes, entities, or general analysis

**Features:**
- Session memory — ask follow-up questions across turns
- Full reasoning transparency — every tool call visible in real time
- Structured prompt harness for consistent, reliable outputs
- Clean modular architecture following software engineering best practices

## 🔒 Secure Deployment

Zero API keys in source code. All secrets injected at build time via GitHub Actions:

```
Repo source (placeholders)  →  GitHub Actions  →  Live site (real keys injected)
  PASTE_YOUR_API_KEY         →  reads secrets   →  AIzaSy...
  SET_YOUR_PASSWORD_HERE     →  reads secrets   →  your-password
```

**GitHub Secrets used:**

| Secret | Purpose |
|---|---|
| `FB_API_KEY` | Firebase API key |
| `FB_PROJECT_ID` | Firebase project ID |
| `FB_SENDER_ID` | Firebase messaging sender ID |
| `FB_APP_ID` | Firebase app ID |
| `ADMIN_PASSWORD` | Analytics dashboard password |

## 🚀 Deployment

**Frontend** — GitHub Pages via GitHub Actions:
```bash
git add .
git commit -m "update portfolio"
git push origin main
# GitHub Actions runs deploy.yml → injects secrets → deploys to gh-pages branch
```

**Backend** — Render (FastAPI):
- `main.py` serves two endpoints: `/chat` (portfolio assistant) and `/agent/run` (research agent)
- Set `GROQ_API_KEY` as environment variable in Render dashboard
